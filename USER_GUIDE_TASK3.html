1. About CampusConnect

CampusConnect is a student-focused platform for Emeris Sandton. It allows students to find and advertise marketplace items, accommodation and services in one moderated environment. Students can also upload images, save favourite listings, message each other in real time and reset forgotten passwords.

RoleWhat the role can do
StudentBrowse content, create listings with images, save favourites, message other students, report content, reset password and manage profile information.
AdministratorManage users, listings, accommodation, services and reports.

2. Before You Start

Hosted use

Open the final hosted application URL in a current version of Microsoft Edge, Google Chrome or Mozilla Firefox. The correct URL must be supplied by the project team.

Local setup requirements

  • Visual Studio 2022 with the ASP.NET and web development workload.
  • .NET 8 SDK.
  • SQL Server LocalDB, SQL Server Express or another compatible SQL Server instance.
  • Git, if downloading the project from GitHub.

Local setup

  1. Download or clone the project repository.
  2. Open CampusConnect/CampusConnect.sln in Visual Studio.
  3. Allow NuGet packages to restore.
  4. Use a local database connection for local testing. Never commit production credentials.
  5. Set the web project as the startup project and run the HTTPS profile.
  6. Confirm that the database starts and demonstration data appears.
Important: Use demonstration credentials only for academic testing. Never reuse them on a real service.

4. Navigation

Public pages

Visitors can access the landing page and public marketplace browsing pages. Public marketplace details and the read-only marketplace API do not require login.

Student navigation

After login, use the student navigation to open Dashboard, Marketplace, Accommodation, Services, Messages, Saved, Profile and Logout. Posting, reporting, saving favourites and messaging require authentication.

Administrator navigation

Administrators can open the Admin dashboard, Marketplace management, Accommodation management, Services management, Reports, Users and Logout.

5. Registering an Account

  1. Open the landing page and choose Register.
  2. Enter your full name.
  3. Enter a university-style email ending in .edu or .ac.za.
  4. Enter a password with at least eight characters and a digit.
  5. Select your faculty and year of study.
  6. Submit the form and correct any validation messages.
  7. After success, the account receives the Student role and the user is signed in.

Registration problems

  • Email rejected: use an approved university-style domain.
  • Password rejected: use at least eight characters and include a digit.
  • Email already used: sign in with the existing account or use the forgot password link.
  • Missing information: complete every required field.

6. Logging In and Out

  1. Select Login.
  2. Enter your email and password.
  3. Select Remember me only on a private device.
  4. Select Login. Students go to the student dashboard; administrators go to the admin dashboard.
  5. Select Logout when finished.

Several failed attempts may temporarily lock the account. Wait for the lockout period or use the forgot password link to reset your password.

7. Using the Marketplace

Browse listings

  1. Open Marketplace.
  2. Search by title or description.
  3. Choose category or condition filters.
  4. Choose a sort order such as newest, lowest price or highest price.
  5. Select a listing to view its details.

The details page shows the title, description, price, category, condition, location, posting information, uploaded images and seller details where available.

Create a listing

  1. Sign in as a student and select Post a listing.
  2. Enter title, price, category, condition, description and location.
  3. Upload up to 5 images by selecting Upload images and choosing files from your device.
  4. Submit the form and read the success message.
  5. The signed-in account is recorded as the seller by the server.
  6. If moderation is enabled, an administrator must approve the listing before it becomes available.

Save a listing to favourites

  1. Open a listing details page.
  2. Select the Save button (heart icon).
  3. The listing is added to your saved items.
  4. Select Saved in the navigation to view all your saved listings.
  5. To remove a saved listing, select the filled heart icon on the listing or the remove button on the saved items page.

Message a seller

  1. Open a listing details page.
  2. Select Message seller.
  3. A conversation is created between you and the seller.
  4. Type your message and send it. Messages appear in real time.
  5. Access all your conversations from the Messages navigation item.

Mark an item as sold

  1. Open a listing you own.
  2. Select Mark as sold and confirm if prompted.
  3. Check the updated status on the details page.

Report a listing

  1. Open the listing details page.
  2. Select Report.
  3. Enter a clear reason and submit.
  4. A pending report is created for administrator review.

8. Using Accommodation

Find accommodation

Open Accommodation, review the listings, use available filters and select a property for full details. Review rent, location, bedrooms, bathrooms, furnishing, availability, image, description and contact information.

Create accommodation

  1. Sign in and select the accommodation creation action.
  2. Enter title, property type, rent, location, bedrooms, bathrooms, furnishing, availability and description.
  3. Upload an image of the property.
  4. Add contact information where requested.
  5. Submit and correct any validation messages.
  6. Refresh the page to confirm the saved record.

9. Using Services and Reviews

Find a service

  1. Open Services.
  2. Browse the service cards and filter by category.
  3. Select a service to view its description, price, provider, image and reviews.
  4. Use the provider contact option where available.

Advertise a service

  1. Sign in and select Create service.
  2. Enter the service title, category, price and description.
  3. Upload an image representing your service.
  4. Submit the form and confirm the service details.

Review a service

  1. Open the service details page.
  2. Enter a rating and respectful review where the form is available.
  3. Submit and check the updated review and average rating.

10. Using Favourites

  1. Browse the marketplace and open any listing.
  2. Select the heart icon to save the listing.
  3. Open Saved in the navigation to see all your saved listings.
  4. Select a saved listing to return to its details page.
  5. Select the filled heart or remove button to unsave a listing.

11. Using Real-Time Messaging

  1. Open a listing and select Message seller to start a conversation.
  2. Alternatively, open Messages from the navigation to see all your conversations.
  3. Select a conversation to open the chat window.
  4. Type your message in the input field and press send.
  5. Messages are delivered in real time using SignalR. The other user sees your message immediately if they are online.
  6. Unread message counts appear on the conversation list.
  7. Messages are marked as read when you open a conversation.

12. Resetting Your Password

  1. On the login page, select Forgot password?.
  2. Enter your university email address.
  3. Submit the form. A password reset link is generated.
  4. In development mode, a reset link is displayed on screen. In production, the link is sent to your email.
  5. Open the reset link and enter your new password twice.
  6. Submit the form. You can now log in with your new password.

13. Managing Your Profile

  1. Open Profile after signing in.
  2. Review your name, faculty, year and account information.
  3. Select Edit profile.
  4. Update the fields that need changing.
  5. Submit and confirm the updated information.

14. Administrator Guide

Dashboard

Log in with an administrator account. The dashboard displays counts for users, listings, accommodation, services and pending reports.

Marketplace management

Open Admin > Marketplace. Search by title or seller, filter by status, approve suitable pending listings or remove content that violates platform rules.

Accommodation and services

Open the relevant management page, review records and remove content only when moderation or the owner's request requires it.

Reports

Open Admin > Reports, filter by status, review the reason and select Resolve or Dismiss. Confirm that the status changes.

Users

Open Admin > Users. Use verification controls only after checking the account. Select Make admin only for authorised staff or project administrators.

15. API Guide

The application includes a read-only marketplace API for programmatic access.

EndpointPurpose
GET /api/marketplaceapiReturns marketplace listings. Optional values include query, category, condition and sortBy.
GET /api/marketplaceapi/{id}Returns one marketplace listing by identifier.

Example: /api/marketplaceapi?category=Textbooks&sortBy=price-low

Swagger is configured for Development. Open /swagger on a local Development instance to view and test the endpoints.

16. Troubleshooting

ProblemWhat to check
Page does not loadConfirm the application is running and use the correct HTTPS URL.
Login failsCheck the credentials, whether the account is locked, or use the forgot password link.
Admin page is blockedConfirm that the account has the Admin role.
Image upload failsCheck that the file is JPG, PNG, WebP or GIF and under 5MB.
Messages not appearingRefresh the page. SignalR reconnects automatically.
New record is not visibleCheck validation messages, refresh the page and confirm the database connection.
Database error on startupCheck SQL Server availability and the local configuration.
API returns not foundConfirm the route and listing ID.
Deployment failsOpen GitHub Actions, identify the failed step and check hosting settings.

17. Safe Use Guidelines

  • Use only your own account details.
  • Do not publish private information in listings.
  • Meet other users in safe, appropriate locations.
  • Report suspicious, abusive or misleading content.
  • Administrators should review moderation actions carefully.
  • Never commit passwords, connection strings or deployment secrets to source control.
All features are fully implemented and functional: image uploads, favourites, real-time messaging and password reset are all working in the hosted environment.
